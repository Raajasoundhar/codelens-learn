# Contributing to CodeLens Learn

This project is an early local prototype. Small, focused improvements are welcome.

1. Open an issue describing the problem or learning need. Use a short synthetic snippet, not private code or credentials.
2. Fork the repository, create a branch, and make your change.
3. Run `npm test` and `npm run check` with Node.js 22 or later.
4. For interface changes, check keyboard navigation, narrow screens, both sample lessons, loading, and error states.
5. Open a pull request explaining the change and what you checked.

Keep sample lessons honestly labeled as prewritten. Never add real API keys, `.env` files, telemetry, or paid calls to tests. Preserve safe text rendering for both user code and model responses.

For bug reports, include Node version, operating system, reproduction steps, and expected behavior. Redact tokens and personal data from screenshots.
